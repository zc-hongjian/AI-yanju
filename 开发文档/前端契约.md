# 前端契约（视觉重做 / 外部交付用）

> 用途：把本项目的网页层交给外部 AI / 设计师 / 新前端时，随 `index.html` 一起发过去。
> 视觉可以推翻重做，**行为与契约不能破**；本文列出的 ID、函数名、文案、路由、事件都是
> `tests/` 里真实断言过的，或者后端/交互依赖的。
>
> 基线：2026-11-25，`pytest -q` **300 passed**。改完页面后这个数字必须保持不变（方案 A）。

## 0. 一句话

**允许**：重写 `<style>`、重排 `<body>` 结构、换配色/字体/组件外观、换图标、换动效。
**禁止**：改后端（`web.py`/`graph.py`/…）、改 `tests/`、拆出外部 CSS/JS/图片文件、引入 CDN/外部字体/构建步骤、删除下表里的 ID/函数/字面量。

## 3. 页面形态与状态机

`<body>` 的 class 决定当前形态：

| class | 形态 |
| --- | --- |
| （无） | 首页：大标题 + 玻璃搜索台 + 能力卡 + 示例问题 |
| `mode-workspace` | 工作区：首页内容收起，显示流水线卡片、确认卡、终稿卡 |
| `mode-report` | 报告阅读页：三栏（目录 / 正文 / 证据） |
| `online` / `offline` | `#mode-pill` 的后端状态（在线 LLM / 离线启发式） |
| `demo`（`#mode-pill.demo`） | `file://` 静态演示：JS `demoMode=true`、显示 `#demo-banner`、隐藏历史按钮，不请求后端 |

一次研究的状态序列（前端卡片）：`idle` → `running`（14 段进度）→ `draft_review` 中断
→ `email_confirmation` 中断 → `notion_confirmation` 中断 → `completed`；异常分支：
`cancelled`（用户取消）、`interrupted`（断流/后端退出，冻结进度标红）、`error`（后端报错）。

**不可改的交互规则**

1. 进度条 14 段**只增不减**；补检回环不倒退；
2. 折叠只折叠日志表（`progress-log`），**不能**折叠整块 `progress-body`；
3. 中断/断流时显示「已中断 · 第 N/14 步」与「会话未完成」卡片，不能伪装成完成；
4. 取消只在节点边界生效，显示「已取消 · N%」而不是连接错误；
5. 报告页**只读**：不调 `/api/research`、`/api/resume`、`/api/config`；
6. 所有写操作必须等人工确认（三次 `interrupt`）。

## 4. 接口契约（前端只能调这些）

完整字段见 [`接口文档.md`](接口文档.md)。前端实际使用的集合：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/research/stream` | 开始研究（NDJSON 流） |
| POST | `/api/resume/stream` | 提交人工确认（NDJSON 流） |
| GET | `/api/sessions?limit=&q=&status=` | 历史会话列表 |
| GET | `/api/sessions/{thread_id}` | 加载单个会话（含中断载荷，可继续审批） |
| DELETE | `/api/sessions/{thread_id}` | 删除会话（连带 checkpoint） |
| POST | `/api/sessions/{thread_id}/interrupt` | 断流时把会话标记为 interrupted |
| POST | `/api/sessions/{thread_id}/cancel` | 协作式取消 |
| GET | `/api/sessions/{thread_id}/diff` | 与上一轮报告 diff |
| GET | `/api/sessions/{thread_id}/export.docx` | 下载 Word |
| GET | `/api/trace/{trace_id}` | 节点耗时/token/成本瀑布 |
| GET | `/api/cost/summary?days=7\|30` | 成本看板聚合 |
| GET/POST/DELETE | `/api/config`、`/api/config/test` | 模型设置（Key 只存后端内存） |
| GET/POST | `/api/kb`、`/api/kb/reindex` | 知识库面板 |
| GET | `/api/health` | 探活（启动页也用） |

**NDJSON 流事件**（每行一个 JSON）：

```jsonc
{"type":"start","thread_id":"web-…","trace_id":"…"}
{"type":"log","entry":{"step_id":"S001","node_name":"…","status":"ok","latency_ms":0,"…":""}}
{"type":"result","data":{ /* 完整响应结构 */ }}
{"type":"error","message":"…"}      // 或
{"type":"cancelled","thread_id":"…"}
```

约定：第一行一定是 `start`；`log` 按 `step_id` 去重追加；最后是 `result`/`error`/`cancelled`；
**没收到 result 就断流 = interrupted**（调 `/interrupt` 落库并标红）。

**三次中断的载荷**（`interrupt.type`）：

| type | 关键字段 | resume.value |
| --- | --- | --- |
| `draft_review` | `draft_report`、`sources`、`evidence_count`、`coverage_summary`、`verification`、`draft_review`、`outline` | `{"decision":"approve\|revise\|terminate","comment":"…"}`，可加 `"edited_report"` |
| `email_confirmation` | `email:{to,subject,body}` | `{"send":true,"email_payload":{…}}` / `{"send":false}` |
| `notion_confirmation` | `notion:{title,tags,content}` | `{"save":true,"notion_payload":{…}}` / `{"save":false}` |

## 6. JS 契约

- **只允许一个内联 `<script>`**（无 `src`）。`test_markdown_render` 用 `<script>(.*?)</script>`
  截取整段脚本做 `node --check`，并从 `function escapeHtml` 截到 `function statusChip`
  运行 `renderMarkdown` 测试。
- `renderMarkdown` 必须存在，且对畸形表格行（如 `"| a | b\nnext line"`）不会死循环。
- `const NODE_ORDER = [...]` 必须逐字等于后端节点顺序（当前 14 个）：
  `receive_question, plan_research, search_web, fetch_pages, retrieve_knowledge,
  summarize_sources, check_coverage, plan_outline, draft_report, draft_review,
  human_review_draft, human_confirm_actions, execute_actions, finalize`
- `STAGE_TOTAL = NODE_ORDER.length`；`STAGE_FUN`、`NODE_LABELS` 必须覆盖全部 14 个节点。
- `STATUS_TEXT` 必须覆盖：`completed` / `completed_no_sources` / `completed_with_action_failure` /
  `terminated_by_user` / `cancelled`（全部中文）。
- 工具函数 `$`、`escapeHtml`、`api`、`apiStream`、`fetchJson` 建议原样保留。
- 状态机入口建议保留：`setLayout("report"|"workspace")`、`startResearch`、`resume`、
  `loadSession`、`loadReport`、`loadHistory`、`openSettings`、`openHistory`、`openCost`、
  `enableDemoMode`、`startDemoResearch`、`markProgressInterrupted`、`markProgressCancelled`、
  `showDraft`、`showEmail`、`showNotion`、`showFinal`、`showUnfinished`、`setFollowUp`。
- 完整函数清单（95 个）与 136 个 DOM id 可直接从当前 `index.html` 扫出，本文只列被测试/行为依赖的。

## 10. 验收清单（方案 A）

7. 打印预览白底单栏，目录/侧栏隐藏；
8. 浏览器控制台无 JS 报错。
