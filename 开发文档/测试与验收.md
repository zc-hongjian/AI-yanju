# 测试与验收

> 从 README 下沉的测试细节与验收对照。当前状态：**40 个测试文件 / 247 个用例全绿**，
> 9 项功能闭环验收 **9/9**，知识库专项验收 **6/6**。

## 1. 怎么跑

```bash
# 全量单元/集成/端到端测试
pytest -q

# 9 项功能闭环验收（会真实跑图。脚本在仓库根目录生成 FUNCTIONAL_ACCEPTANCE.md，
# 该文件已 gitignore；本目录下的是归档副本）
python evaluation/acceptance_check.py

# 知识库专项验收：只给 knowledge/、禁止联网
python evaluation/kb_check.py
```

测试公共夹具见 [`tests/conftest.py`](../tests/conftest.py)：

- 强制 `AGENT_LLM_MODE=offline`、清空 API Key，保证测试不访问真实模型；
- 用本地假网页/假搜索替换 `search_web` / `fetch_page`（`fake_web`）；
- 把 `data/`（checkpoint、sessions、KB 索引）重定向到 `.tmp/pytest-data/run-*`，不污染仓库；
- 默认知识库指向空目录，RAG 用例自己建临时文档；
- 默认关闭搜索/抓取缓存（`AGENT_CACHE_ENABLED=0`）并隔离缓存/写操作审计库，
  避免“本该真调工具”的用例被缓存短路；缓存用例自己 `monkeypatch` 打开并指到临时库。

## 3. 9 项功能闭环验收对照

`evaluation/acceptance_check.py` 逐条检查并生成报告（[FUNCTIONAL_ACCEPTANCE.md](FUNCTIONAL_ACCEPTANCE.md)）：

| 验收标准 | 实现位置 |
| --- | --- |
| 跑通完整流程 | `main.py` + `tests/test_graph_flow.py::test_full_flow_writes_only_after_both_approvals` |
| 草稿确认前不写邮件/Notion | `graph.py` 条件边；测试断言每次确认前 `outbox` 为空 |
| 三处人工暂停（草稿 / 邮件 / Notion） | `graph.py` 三个 `interrupt()`；`human_review.py` 三个确认函数 |
| 未确认写操作直接拒绝 | `tools.call_tool()` 写操作门禁 + `WriteActionNotApproved` |
| 失败重试 3 次并记录日志 | `tools.retry_call()`；测试断言退避与重试次数 |
| 日志按 step_id 串起链路 | `logging_utils.py` + JSONL + 日志表 |
| 结论带可验证引用 | 报告用 `[S#]` 角标；`_sanitize_report()` 按证据重建来源清单并清洗未抓取 URL |
| 问题拆解 3~5 个子问题 | `plan_research` → `plan.sub_questions`；日志 S002 记录子问题数 |
| 子问题覆盖 / 缺口补检 | `check_coverage` + `quality.compute_coverage`；覆盖率/轮次写入 `final_output` |
| claim 支持性校验 | `quality.verify_evidence`；支持率写入 `final_output.verification` |
| 可观测（token/成本/耗时） | `final_output` 含 `token_usage / cost_cny / duration_ms / log_summary` |
| 40 题评测 + 报告 | `evaluation/`：`run_eval.py` + `make_report.py` → [eval_report.md](eval_report.md) |
| 9 项功能闭环验收 | `evaluation/acceptance_check.py` → [FUNCTIONAL_ACCEPTANCE.md](FUNCTIONAL_ACCEPTANCE.md) |
| 会话持久化 / 重启恢复 | `persistence.py` + `web.py`：SQLite checkpointer；`tests/test_persistence.py` |
| 调用链 Trace / 节点成本 | `tracing.py` + `graph._instrument`；`/api/trace`、`/api/cost/summary`、`config/pricing.json` |
| 知识库混合检索 | `rag.py` + `retrieve_knowledge`；`knowledge/`、`evaluation/kb_check.py`（6/6） |
