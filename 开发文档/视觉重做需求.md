# 视觉重做需求（前端改版 Brief）

> 给外部 AI / 设计师 / 新前端：本项目的**视觉层推翻重做**需求。
> 配套文件：[前端契约.md](前端契约.md)（ID/函数/断言清单，必须遵守）、[接口文档.md](接口文档.md)（能调哪些接口）。
>
> 基线：2026-11-25，`pytest -q` **300 passed**；页面是两个静态单文件（`index.html`、`launch.html`）。

---

## 1. 背景与目标

现状：一个 LangGraph 研究助手 Web 端，页面是单文件深色科技风（玻璃拟态搜索台、14 段进度、
三次人工确认、报告阅读页、历史/成本/设置/知识库）。视觉上已经“够用”，但设计语言偏旧、
组件重复度高，想整体推翻重做。

目标：

1. **视觉全面升级**：新的设计语言（配色/字体层级/间距/圆角/阴影/图标/动效），桌面优先、兼顾窄屏；
2. **信息架构更好用**：首页→工作区→确认→终稿→报告页的动线更清楚更少打断；
3. **不破坏功能**：接口、三次中断、断流/取消/中断态、报告页只读、`file://` 静态演示全部保留；
4. **零构建、零外部依赖、零后端改动**：仍是 `index.html` / `launch.html` 两个单文件。

## 2. 范围

| 做 | 不做 |
| --- | --- |
| 重写 `index.html` 的 `<style>` 与 `<body>` 包装结构（视觉效果、布局、组件外观） | 不改 `web.py` / 后端 `.py` / `tests/` |
| 重写 `launch.html` 的视觉（保持一键启用行为） | 不引入 React/Vue/Tailwind/TS/构建步骤 |
| 图标、插画、空态、错误态、加载态、动效 | 不使用 CDN、外部字体、外链图标库 |
| 重拍 `原型图/` 22 张截图（同名覆盖） | 不拆出 `.css`/`.js`/图片文件（未挂 StaticFiles 会 404） |
| 在 `index.html` 内保留契约要求的 ID/函数/文案 | 不删三次确认、深链、报告页只读约束 |

**硬性边界**：方案 A（推荐）= 视觉层重做，DOM 骨架/ID/JS 契约不动；
方案 B = 连结构重写，必须同步迁移 10 个测试文件 21 个断言（见前端契约 §12），另行排期。

## 4. 页面内容与状态明细

### 4.1 首页（landing）

- 大标题 + 一句价值主张；居中玻璃搜索台（问题输入 + 开始按钮 + 快捷键提示）；
- 4 张能力卡（如：多源检索 / 证据可回溯 / 三次人工确认 / 报告导出）；
- 示例问题 chips（点击填入）；
- 顶栏：品牌、状态灯（后端在线/离线）、历史、成本、设置；
- 空态/离线态：后端不可用时给出「先启动 `web.py`」提示，不白屏。

### 4.2 工作区 + 执行进度

- 顶部一条问题输入（可改问题重开）+ `thread_id`/模式 pill；
- 14 段分段进度条（每段一个节点格子）：节点名、状态色（ok/degraded/error/rejected/skipped/approved）、
  阶段表情 + 文案 + 百分比（`aria-valuenow`）；
- 实时日志表（step_id/节点/工具/状态/耗时/输入输出摘要），可「收起日志」但进度条保留；
- 进度**只增不减**，补检回环不倒退；
- 右上角「取消运行」；取消后显示「已取消 · N%」。

### 4.3 草稿确认（`draft_review`）

- 草稿 Markdown 正文（滚动区）+ 元信息（证据数、覆盖度、引用校验摘要）；
- 三个动作：通过并继续 / 填修改意见重新生成 / 终止；
- 修改意见输入框 + 提交（最多 2 轮重写）；通过后进入邮件确认。

### 4.4 邮件确认（`email_confirmation`）

- 收件人、主题、正文可编辑（正文默认是研究报告 Markdown 摘要）；
- 「发送」/「跳过」；发送前做邮箱格式校验；
- 明确提示：确认前不会产生任何写操作。

### 4.5 Notion 确认（`notion_confirmation`）

- 标题、标签、正文可编辑；「保存」/「跳过」。

### 4.6 终稿卡

- 报告正文（可折叠长文）、最终状态（中文标签 + 英文 title）、关键指标（证据数/覆盖/耗时/token/成本）；
- 来源清单、证据表（编号/结论/来源/定位/可信度/标记）；
- 写操作结果、错误与降级（摘要级证据/无来源等）；
- 下载 Markdown、下载 Word、进入报告页、继续追问、查看完整日志、Trace 入口。

### 4.7 报告阅读页（`mode-report`，只读）

- 三栏：左目录（含覆盖度/引用校验/告警 chips）、中正文、右证据；
- `[S#]` 可点 → 右侧高亮对应证据卡；点证据卡 → 反查正文高亮引用处；
- 字号 S/M/L（记住选择）、打印/导出 PDF（白底单栏、隐藏目录与侧栏）、复制链接、下载 Markdown；
- 「与上一轮对比」diff 面板（红绿增删，不含来源列表）；「继续追问」；
- **只读**：不出现研究/恢复/设置接口调用。

### 4.8 历史抽屉

- 列表：问题、时间、状态（含 `interrupted` 已中断）、追问链标识；
- 搜索框（问题/会话号）+ 状态筛选；
- 行内操作：继续审批 / 查看 / 删除（页面内确认弹层，不弹浏览器 confirm）；
- 删除后列表刷新、会话与 checkpoint 一起清。

### 4.9 成本看板

- 7/30 天切换；总量（运行数、模型调用、token、¥成本）+ 按模型、按天拆分；
- 空数据态；免费模型标注（¥0 不是 bug）。

### 4.10 模型设置 + 知识库面板

- 提供方预设（智谱 GLM 等）、API Key（密码框 + 掩码显示 + 显示/隐藏）、Base URL、模型名；
- 测试连接（真实最小调用）、保存到后端进程内存、清除运行时配置；
- 明确提示：Key 不落盘、不回传明文、重启失效；
- KB 面板：文档数/分块数/是否启用向量 + 「重建索引」。

### 4.11 中断 / 取消 / 失败态

- 断流/后端退出：进度冻结标红「已中断 · 第 N/14 步」+「会话未完成」卡片（重新开始/删除）；
- 取消：协作式，节点边界生效，显示「已取消 · N%」；
- 后端错误：错误条 + 可重试提示；
- 全部不能伪装成「完成」。

### 4.12 报告对比 / Word / 追问

- diff：正文增删行统计、红绿标记、关闭；
- Word：终稿卡/报告页都能下载 `.docx`；
- 追问：输入框上方提示「基于上一轮结论追问」，可退出；开始研究时带 `parent_thread_id`。

## 5. 交互规则（不可改）

1. 三次人工确认（草稿/邮件/Notion）顺序不变，写操作只在确认后；
2. 进度 14 段只增不减；折叠只折叠日志表；
3. 报告页只读；
4. 深链：`?settings=1`、`?history=1`、`?session=<tid>`、`?q=…&autostart=1`、`/app?follow=<tid>`、`?collapse=1`；
5. `file://` 双击进入静态演示（示例数据走完整流程），不请求后端；
6. 后端离线时首页/启动页给出启动方式，不白屏；
7. 长状态文本（如 `completed_with_action_failure`）中文优先、不撑破布局；
8. 所有列表空态/加载态/错误态都要设计（历史、成本、KB、证据、日志）。

## 6. 视觉方向（可推翻部分）

> 这块是唯一可以完全推翻的：配色、字体、布局、组件外观、图标、动效都由你定。
> 但必须**token 化**，便于后续维护。

### 6.1 三种可选方向（任选其一或自定）

- **A 专业研究工具**：浅色/中性底色 + 一个强调色（蓝/青），信息密度高，克制的卡片与表格；
- **B 深色科技**：深色底 + 玻璃拟态 + 霓虹强调色，动效轻，适合演示；
- **C 极简文档风**：大量留白、衬线标题 + 无衬线正文、弱边框，报告阅读体验优先。

### 6.2 必须 token 化的设计变量

| 类别 | 内容 |
| --- | --- |
| 色彩 | 背景/表面/边框/文字（3 级）/主色/语义色（成功/警告/错误/中断）/图表色 |
| 字体 | 中文系统字体栈（禁止外部字体）；字号阶梯（如 12/13/14/16/18/22/28）；行高 |
| 间距 | 4/8 基准，`--u` 等比因子（现有代码用 `calc(N * var(--u))`，可沿用或换自己的） |
| 圆角/阴影 | 卡片/按钮/弹层三档 |
| 动效 | ≤200ms，进度/弹层/toast；`prefers-reduced-motion` 降级 |
| 图标 | 内联 SVG 或 emoji，禁止图标库 |
| 布局 | 桌面优先 1280+；1024/768 断点；报告页三栏 → 两栏 → 单栏 |

### 6.3 关键视觉对象

- 首页搜索台（视觉重心）、14 段进度（状态色 + 动效）、确认卡（防止误操作的层级）、
  报告页三栏（阅读体验 + 证据联动）、历史/成本/设置的弹层与抽屉。

## 8. 响应式 / 无障碍 / 打印

- 断点：≥1280 三栏（报告页）、1024 两栏、768 以下单栏；工作区在小屏下确认卡纵向排列；
- 键盘可操作：弹层焦点圈、Esc 关闭、Tab 顺序；按钮有 `:focus-visible`；
- 对比度 ≥ WCAG AA（正文 4.5:1）；状态不只靠颜色（加文字/图标）；
- 进度条 `role="progressbar"` / `aria-valuenow`；图标按钮有 `aria-label`；
- 打印：白底、单栏、隐藏目录/侧栏/按钮，保留正文与来源清单；
- 动效尊重 `prefers-reduced-motion`。
